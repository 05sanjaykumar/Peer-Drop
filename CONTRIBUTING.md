# Contributing to Peer Drop

Thank you for your interest in contributing! Your help is greatly appreciated.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Clone your fork** and make your changes.
3. **Write clear, concise commit messages**.
4. **Test your changes** before submitting a pull request.
5. **Open a pull request** with a detailed description of your changes.

## Code Style

- Follow Go best practices and conventions.
- Run `go fmt ./...` before committing.
- Keep code modular and well-documented.

## Reporting Issues

- Use [GitHub Issues](../../issues) to report bugs or request features.
- Provide steps to reproduce, expected behavior, and screenshots if possible.

## Pull Request Checklist

- [ ] Code compiles and passes all tests.
- [ ] Linting and formatting checks pass.
- [ ] Documentation is updated if needed.

## Community

Be respectful and constructive in all communications.
